A-09 — SRS / İlerleme API

SM-2 aralıklı tekrar algoritmasının durumunu tutan entity katmanı — sistem kelimesi (UserProgress) ve kişisel kart (UserCardProgress) ilerlemesi ayrı tablolarda, her cevap denemesinin insert-only geçmişi (LearningHistory) ve statik başarım referans tablosu (Achievement/UserAchievement). Bu görev devam ediyor — SrsCalculator/ProgressService/ AchievementService henüz bu akademiye işlenmedi.

  1. 1 UserProgress / UserCardProgress Entity Katmanı Domain/Entities/Srs/ (ilk kez), NextReviewAt nullable, ConsecutiveIncorrect/IsSuspended leech alanları, UNIQUE (UserId, WordId|UserCardId).
  2. 2 LearningHistory, Achievement/UserAchievement ve Migration İnsert-only geçmiş kaydı, statik başarım referans tablosu + AchievementRarity enum, 5 tabloyu üreten migration — gerçek ZauselDB'ye uygulanıp canlı doğrulandı.
