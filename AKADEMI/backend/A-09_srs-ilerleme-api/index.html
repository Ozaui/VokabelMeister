A-09 — SRS / İlerleme API

SM-2 aralıklı tekrar algoritmasının durumunu tutan entity katmanı — sistem kelimesi (UserProgress) ve kişisel kart (UserCardProgress) ilerlemesi ayrı tablolarda, her cevap denemesinin insert-only geçmişi (LearningHistory), statik başarım referans tablosu (Achievement/UserAchievement) ve durumu GERÇEKTEN hesaplayan SrsCalculator. Bu görev devam ediyor — SrsCalculatorTests/ProgressService/AchievementService henüz bu akademiye işlenmedi.

  1. 1 UserProgress / UserCardProgress Entity Katmanı Domain/Entities/Srs/ (ilk kez), NextReviewAt nullable, ConsecutiveIncorrect/IsSuspended leech alanları, UNIQUE (UserId, WordId|UserCardId).
  2. 2 LearningHistory, Achievement/UserAchievement ve Migration İnsert-only geçmiş kaydı, statik başarım referans tablosu + AchievementRarity enum, 5 tabloyu üreten migration — gerçek ZauselDB'ye uygulanıp canlı doğrulandı.
  3. 3 SrsCalculator — SM-2 Algoritması Static, DI'siz saf hesaplama — Calculate (interval/level/EF) + CalculateMastery (yüzdelik formül). A-09 şimdiye kadarki özet burada.
