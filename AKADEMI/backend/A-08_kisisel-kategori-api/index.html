A-08 — Kişisel Kategori API

Kullanıcının kendi kartlarını gruplamak için kullandığı kişisel kategori — sistem Category'sinden bağımsız, projenin ilk PersonalContent domain'i ve ilk gerçek AutoMapper kullanımı. GET/POST/PUT/DELETE, sahiplik filtresi repository'de gömülü.

  1. 1 UserCategory Entity ve Repository Katmanı Domain/Entities/PersonalContent/ (ilk kez), UserCategoryConfiguration, IUserCategoryRepository/UserCategoryRepository — sahiplik filtresi GetByIdForUserAsync'te gömülü.
  2. 2 Projenin İlk AutoMapper Profile'ı ve CRUD Komutları UserCategoryProfile, CreateUserCategoryCommand+Handler, validator, Program.cs'e AddAutoMapper kaydı; Update/Delete/GetUserCategories temsili öğretimle.
  3. 3 UserCategoriesController ve Canlı Doğrulama 4 endpoint (GET/POST/PUT/DELETE), [Authorize] (Admin değil), 5 postman slaytı — canlı curl istekleriyle doğrulandı.
