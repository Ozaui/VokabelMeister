A-10 — Kişisel Kart API

Kullanıcının kendi eklediği kelime kartı (UserCard), kartın örnek cümlesi (UserCardExample) ve kartı hem sistem kategorilerine hem kendi kişisel kategorilerine bağlayan iki ara tablo (UserCardCategory/UserCardUserCategory) — entity katmanı ve migration tamamlandı, servis/ controller/testler devam ediyor.

  1. 1 UserCard Entity Katmanı ve Migration Domain/Entities/PersonalContent/ (UserCategory ile aynı klasör), UserCardUserCategory'nin NoAction FK'si ("multiple cascade paths" tuzağı), A-09'un bekleyen UserCardId FK'lerinin tamamlanması, gerçek ZauselDB'ye uygulanıp canlı doğrulandı.
