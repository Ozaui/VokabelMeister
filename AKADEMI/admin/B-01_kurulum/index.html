B-01 — Kurulum

Herhangi bir ekran yazılmadan önce oturması gereken paylaşılan temel: proje iskeleti ve kütüphaneler, tasarım sistemi (renk/font/radius/gölge), Redux store + API katmanı, dil tercihi, yönlendirme (routing) + temel sayfa iskeleti, dark mode. Bu bölümü bitirmeden B-02'ye geçilmez — sonraki her ekran buranın üzerine kurulur (A-02'nin admin karşılığı).

  1. 1 Proje İskeleti ve Kütüphaneler Vite+React+TS, CLAUDE.md §4.1'deki ortak kütüphane seti, Tailwind v4'ün Vite eklentisi, Vitest kurulumu.
  2. 2 Tasarım Sistemi Renk paleti/font/radius/gölge skalası (Tailwind @theme + .dark override), index.html font yüklemesi, tema doğrulama yer tutucusu.
  3. 3 Redux Store + Auth Slice + API İstemcisi Slice sınırının konu bazlı çizilmesi, authSlice (accessToken/isAuthenticated), store.ts, axios apiClient + Authorization/Accept-Language interceptor'ı, Provider bağlanması.
  4. 4 Dil Tercihi (i18n) languageSlice, react-i18next + tr/de çeviri dosyaları, useLanguageSync köprüsü, Topbar'da LanguageSwitcher (aria-pressed + <html lang> senkronu).
  5. 5 .env, ProtectedRoute, Temel Layout VITE_API_URL, React Router (BrowserRouter/Routes/Outlet), ProtectedRoute, AppLayout + Sidebar/Topbar (mobilde açılır-kapanır panel).
  6. 6 Dark Mode themeSlice (Light/Dark/System), useThemeSync (OS canlı takibi), ThemeSwitcher, index.html'e FOUC-önleyici senkron script.
  7. 7 Özet + Sözlük B-01'in tamamının özeti ve boyunca geçen tüm yeni kavramların sözlüğü — B-02'ye geçmeden önceki kapanış.
