Bir Admin Panel Ekranı Nasıl Yazılır?

Bu akademi, VokabelMeister admin panelini (/admin, React + TS) sıfırdan anlatır — Backend Akademi'nin frontend kardeşi, aynı ilkeyle: hiçbir ön bilgi varsaymadan, her kod satırının ne yaptığını, neden öyle yazıldığını ve böyle yazılmasaydı ne olacağını tek tek anlatır. Klavyede ← → ile slaytlar arası gezin, O tuşuyla İçindekiler'i açın. Aşağıdaki görevleri sırayla okuyun — her biri bir öncekinin üzerine kurulur.

B-01 · KURULUM
Admin Panelin Temeli
React+Vite+TS+Tailwind v4 iskeleti, tasarım sistemi (bir renk kararının gerçek tarayıcıda görülünce nasıl düzeltildiği dahil), Redux store + axios (`apiClient`) + dil tercihi (tr/de) altyapısı, JWT olmadan hiçbir ekranın açılmadığı ProtectedRoute+layout zinciri, ve dark mode (backend'e hiç dokunmayan bir çözüm — ThemePreference zaten vardı).
7 bölüm · başlangıç noktası
B-02 · AUTH SAYFALARI
Giriş + OTP Doğrulama
Admin panelin İLK gerçek ekranları — Formik+Yup'ın ilk kullanımı, backend'e atılan ilk gerçek HTTP istekleri (login + verify-otp), authSlice'a user alanının eklenmesi, ve admin panelde ilk kez kurulan test altyapısı (Vitest + React Testing Library).
7 bölüm · JWT olmadan çalışmıyor
B-03 · KELİME YÖNETİMİ
Kelime CRUD + Gramer Veri Girişi + Eşleştirme
Admin panelin şimdiye kadarki EN BÜYÜK feature'ı — Almanca/Türkçe İsim/Fiil gramer formları (tek bir generic çekim tablosuyla paylaşılan), dinamik örnek cümle listesi, recursive kategori seçici, iki sütunlu kelime eşleştirme ekranı, ve gerçek bir i18n hatasının yakalanıp düzeltilmesi.
12 bölüm · 24/24 test yeşil · gerçek tarayıcıda uçtan uca doğrulandı
