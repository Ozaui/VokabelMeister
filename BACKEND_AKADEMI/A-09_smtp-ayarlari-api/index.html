A-09 — SMTP Ayarları API (tamamlandı)

SMTP bilgileri admin panelden yönetilir, `appsettings.json`'da DEĞİL — DB'de AES-256-CBC ile şifreli tutulur. Bu görev tek satırlık (singleton) bir `SmtpSettings` tablosu, bu şifreyi şifreleyen/çözen `IEncryptionService`/`AesEncryptionService`, GET'te şifreyi "***" ile maskeleyip PUT'ta aynı maske geri gelirse eskisini koruyan bir sözleşme, ve admin panelin ayarları GERÇEKTEN test edebilmesi için MailKit tabanlı bir `ISmtpTestService` yazdı. Kod denetiminde gerçek bir bulgu çıktı: projenin ENV.md/launchSettings.json örnek `AES_ENCRYPTION_KEY`'i Base64 çözüldüğünde 32 DEĞİL, 29 bayt üretiyordu — düzeltildi.

  1. 1 SmtpSettings Entity + AES-256-CBC Şifreleme DATABASE_SCHEMA.md'nin ad-hoc UpdatedByUserId→BaseEntity birleştirme notu, SmtpSettings entity+migration, IEncryptionService/AesEncryptionService, kod denetiminde bulunan 29 baytlık örnek anahtar hatası.
  2. 2 Repository + GetSmtpSettingsQuery / UpdateSmtpSettingsCommand ISmtpSettingsRepository (singleton satır), şifre maskeleme sözleşmesi (GET "***" döner, PUT "***" görürse korur), upsert Command, IActivityLogger+ISecurityLogger çift loglama.
  3. 3 SmtpSettingsController + ISmtpTestService + Postman MailKit ile gerçek SMTP bağlantısı (ISmtpTestService/MailKitSmtpTestService), TestSmtpSettingsCommand, SmtpSettingsController (GET/PUT/POST test), 3 Postman örneği.
  4. 4 Testler + Özet + Sözlük AesEncryptionServiceTests (gerçek round-trip, Moq yok), kod denetiminde bulunan 2 gerçek düzeltme (maske literal'i + eşzamanlı PUT determinizmi), A-09'un tamamı: 265/265 yeşil test.
